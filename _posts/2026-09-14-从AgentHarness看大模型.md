作为一名学生，在过去的两个月里付费烧掉了数十亿tokens，总算是对适合自己的模型有了比较深刻的体会，遂写一篇随笔，来说一下我个人的使用体验和推荐。

# Trae

作为第一个使用的入门级Tokens工具，只能说还挺好用的。但是上班时间需要排队必须这一点挺坑，因为用的时候刚好是在上学，所以印象分要扣分。用来应付作业足够。

Seed，毕竟是豆包，有时候幻觉挺严重

# Codebuddy

和hy3一块说：我的白月光，本人在付费订阅AI服务之前的深度使用者。课上完了之后刚好想做一些有趣的东西，hy3那时候一直免费。虽然白天和Trae同样需要排队，但是开局就送2000积分也提供给了我接触别的模型的最初的契机，时常深夜蹬hy3蹬到5点多。

对hy3的印象：交流起来很舒服，作为入门级别能引导我完善自己的想法和需求，最重要的是免费日期截至之后依旧保持免费，我蹬了估计也不下十亿个tokens。缺点是上下文只有256k，完全不够用，同时期deepseek已经做到1M上下文了，但是支持图片输入可以很好的和deepseek互补。但是项目长大之后必定爆上下文。

Kimi k3：我没用过他们自家的Tokens工具，所以归类到这里。很聪明，理解能力和代码能力很强，只是太贵了，真的太贵了。

# DeepSeek Harness

Harness自身：神，我非常喜欢这种高度可自定义的项目，我也用deepseek做了好多deepseek的插件，我写的热重载插件管理插件获得了我在GitHub上的第一个star，甚至我写的Gui得到了三个fork（是不是太简陋了更适合用别的语言重写？笑）

DeepSeek flash，调整定价之前与回调定价之后的性价比极高，但是沟通代价有些高，经常搞不懂我的需求，给人的感觉就是：说话常常冷冰冰的，但是干起活来太活泼了（贬义），常常越界，审美也不行，即使多模态上线之后。

累计花费约70元，1亿tokens。

# Codex

当下我的主力开发Tokens，也是我第一次尝试订阅。

Astra：超贵...plus用户根本用不起，低思考强度处理一个表格花了5小时限额的25%，目前没啥使用体验和经验；

Sol：好用！很聪明，只是防御性编程很多，tokens浪费很多，适合作为编排者做架构设计与指挥去指挥deepseek还有Luna干活。

Terra：感觉不上不下，比Luna聪明不了多少，但是贵不少，效率和性价比都不如Sol+Luna。

Luna：真正的性价比之神，个人体验下来要比deepseek聪明好多，最重要的是她可以使用computer use自主调试，加上经常性的额度重置几乎用不完。我的主力开发模型。

只是在Astra上线附近恢复了5小时限额，24小时跑项目Luna也不是很够用了，虽然也可能是因为我的项目现在变得太大了。

订阅+Api中转合计花费200元+148元，tokens累计消耗20亿+

# Hermes

当下我的主力项目维护Tokens，可以接codex订阅！

目前我主要拿 Hermes 做 SlimeMold 的长期维护。它最让我上头的地方，是很适合跑超长 Goal，很多任务可以持续推进很久。

最大的问题是上下文时常会超限，需要另起对话，但是它特别厉害的记忆系统又很好的弥补了这一点。

但是其最大的缺点也是上下文污染，会积累很多的skills，很难丢弃之前的记忆，所以我现在还是更愿意让 Codex 做主力开发，把 Hermes 放在维护和长程任务上。

# WorkBuddy

我的主力项目审查Tokens，同时也是一个好秘书。Hy4能力比Hy3能感觉出来进化了不少，依旧是很适合交流和探讨工作和学习上的事情，我常常使用Workbuddy里面的Hy4或者Deepseek去对抗性审查codex或者Hermes的产出，和Hermes一样记忆会污染上下文，但是其自然轻松温和的人格prompt相比Hermes更适合当作一个“陪伴在身边的助手”。

# Claude Code

我重置pro的第二天我的号就被封掉了，没有深度体验过。

------

目前我的分工：

- Codex：主力开发
- Hermes：维护 / 长程任务
- WorkBuddy：审查 / 对抗性检查
- DeepSeek Harness：高自定义和插件玩具
- 其他模型：补位

当然，这套组合存在时效性。所以这篇文章更像是一张 2026 年 9 月的个人快照。
